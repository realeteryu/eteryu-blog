# Start

Pełna dokumentacja dostępna jest pod adresem [zensical.org](https://zensical.org/docs/).

## Komendy

* [`zensical new`][new] – utwórz nowy projekt
* [`zensical serve`][serve] – uruchom lokalny serwer
* [`zensical build`][build] – zbuduj stronę

  [new]: https://zensical.org/docs/usage/new/
  [serve]: https://zensical.org/docs/usage/preview/
  [build]: https://zensical.org/docs/usage/build/
